Built for AV, not for network engineers

Plug in with a console cable or connect over SSH or Telnet. SwitchCommander handles the CLI so you can get on with the job.

AV essentials built in

IGMP snooping and queriers per VLAN, QoS presets for Dante, Shure and Q-SYS, Green Ethernet settings,and EEE turned off so devices stay online.

See before you send

Every command is previewed. The running config is backed up first, and the app stops at the first command the switch rejects.

Repeatable

Save a configuration as a file and load it onto the next switch on the job, or the next job.

Read what is on the switch

  • Multicast groups per VLAN, with the ports that joined and a best guess at what each carries: PTP, Dante, AES67, sACN or video.
  • Querier status so you know which device is the active querier on every VLAN.
  • MAC table with IP addresses from the switch or a subnet scan, exported to CSV for your as-builts.
  • Running config saved to a file in one click.

Write a configuration from a form

  • VLANs with IP addresses, IGMP snooping, querier and immediate leave.
  • Port profiles like Dante, Control or Uplink trunk. Click ports to assign them.
  • QoS presets for Audinate Dante, Shure and Q-SYS (Q-LAN).
  • DHCP server with address pools per VLAN.
  • Management access: turn SSH, Telnet and the web interface on or off.
  • Leave any box on the dash and the switch keeps what it has.

Download

Install it once and it keeps itself up to date. A licence key, emailed when you buy, activates one computer and works offline for 30 days.

Windows

Windows 10 or 11.

If SmartScreen says Windows protected your PC, click More info, then Run anyway.

Mac

Apple silicon and Intel, in one download.

Drag it to Applications. If macOS won't open it, go to System Settings › Privacy & Security and click Open Anyway. If it says the app is damaged, run this in Terminal:

xattr -dr com.apple.quarantine /Applications/SwitchCommander.app

Linux

.deb for Ubuntu and Debian, .rpm for Fedora, or an AppImage for anything else.

For the USB console port, run once and log back in:

sudo usermod -aG dialout $USER
